## 五、本轮踩过的坑（省时间用）

1. **颜色不是唯一维度**。`div[data-clock]` 的 `opacity: 0` 让整块时间/用量不可见；用户消息行的 opacity 由内联样式控制，普通规则压不过，要 `!important`。宿主的悬停揭示容器属性已从 `data-time-hover-root` 换名（该属性现已不存在）。
2. **皮肤的「浅色面板内压墨色」规则在新版整体反向**：`[data-queue-dock]` 的坞面变透明、`[data-testid='todo-panel']` 的底变深橄榄 `#2c2e24`，墨字于是落在深底上。
3. **只在容器上覆盖 token 会漏**：坞内条目正文走的是 `--dsw-alias-label-primary-dimmed`（浅色主题下是近黑 `#151517`），漏一个 token 就整块发黑。
4. **测量时机**：皮肤 CSS 由 client bundle 异步注入。`browser_navigate` 之后立刻测会读到 token 未定义时的黑色回退值，误判成「修复没生效」。先等 `document.body.hasAttribute('data-dsh-815')` 再取数。
5. `bgOf` 合成背景时要把 `url(...)` 背景按暗底（`#080a06`）算、渐变取平均色，并且**不要**在遇到不透明层时提前 break（否则会漏掉更靠内层的浅色面板）。
