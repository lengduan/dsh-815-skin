# 轨迹视图（宿主 ui-trajectory）

- 状态：生效中（2026-11-11 建立）
- 来源：用户反馈「修复一下轨迹里面有些文字颜色和背景色过于接近的问题，需要修改文字颜色」（截图箭头指向形态标签列与工具行）。

## 目标

会话「轨迹」页里，形态标签（工具 / 子工具 / 上下文 / 助手）、时间线坐标轴、表格箭头、工具结果的错误文字，以及事件详情「参数」页签的 JSON 树语法色，在皮肤的深底上都达到可读阈值；标签的语义色相（琥珀 / 绿 / 紫）保留，不因提亮而丢掉「哪一类事件」的区分。

## 约束

- 锚点按 `specs/项目规格/皮肤样式锚点.md`：容器用宿主手写的 `aria-label='轨迹时间线'` / `aside[aria-label='事件详情']` 与 `data-trajectory-scroll`（均 A 级）；标签用 `data-role-kind`（A 级）。插件 CSS Module 的 `xeixwq_` / `1bv28` 等构建期 hash 前缀不进选择器；JSON 树的 `[class*='_root_']` 是 D 级 localName 后缀，已在 aside 容器内收窄。
- 色彩按 `specs/项目规格/皮肤设计风格.md` 第二、八条：优先重绑主题 token；语义色只取深底档，标签底用同色相深橄榄实色（半透明底在选中行的铜金底上会被抬亮）；文字色在奶油五级 / 代码块 shiki token 内部取档，不新增独立色板。
- 不改宿主与插件源码，不重排节点；只在容器上重绑变量与给一个标签直接上色。

## 涉及文件

- `src/client/vj815.module.css`：文末「会话「轨迹」视图」段三条规则（token 重绑、助手标签直给色、JSON 树语法变量）。
- `specs/功能规格/README.md`：当前清单补本文件。

## 验收

1. 运行时命中：`document.querySelectorAll("[aria-label='轨迹时间线']").length`、`document.querySelectorAll("[data-trajectory-scroll]").length`、`document.querySelectorAll("aside[aria-label='事件详情']").length` 均 > 0；`[data-role-kind]` 的四个取值 `tool / subtool / context / message` 都能在表格里找到。
2. 计算样式 + 逐层合成背景后，轨迹页（含悬停行、选中行、展开的事件详情与「参数」页签）文字对比度 <4.5:1 的元素数为 0。2026-11-11 本机客户端实测：工具 7.88:1、子工具 7.15:1、上下文 7.61:1、助手 8.91:1、箭头 9.27:1、坐标轴 8.42:1、错误文字 7.60:1、JSON 键名 6.81:1 / 字符串 9.65:1 / 标点 11.27:1。
3. 标签语义可辨：四个形态标签仍是琥珀 / 绿 / 紫三组色相，选中行与未选中行都不回落到「同色糊住」。
4. `pnpm test` 通过；卸载 / 禁用皮肤后 `body[data-dsh-815]` 与相关样式不残留（现有 JS 侧测试覆盖卸载撤回，CSS 命中数按第 1 条人工核对）。

## 已知边界

- 时间线容器锚点用的是宿主中文 `aria-label='轨迹时间线'`；宿主若改文案或做多语言，该条会失配，需要按新文案更新锚点。`data-trajectory-scroll` 与 `data-role-kind` 不受文案影响，表格那部分仍然成立。
- JSON 树变量只在事件详情面板内重绑；其它入口（如对话里的工具卡）若也用同一组件，仍是浅色主题语法色，未在本需求范围内实测。
