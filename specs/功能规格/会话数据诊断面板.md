# 会话数据诊断面板

- 状态：生效中（2026-11-20 建立）
- 范围：侧栏「会话数据诊断」页（宿主插件 `@deepseek-ai/dsh-experimental-session-inspector`）的表格与详情抽屉配色。

## 目标

面板在皮肤深底上整片可读：表头、行正文、类型筛选、详情抽屉里的文字对各自底色 ≥ 4.5:1，不出现「浅色横条上糊着奶油字」的白斑。

## 症结

表头（序号 / 类型 / T/S / 时间 (UTC) / 数据）是 sticky 行，底取宿主 `--dsw-alias-bg-module-platform`。皮肤不接管该 token，浅色宿主主题下它是近白 `#f5f6f7`；字却走皮肤全局奶油 `--dsw-alias-label-primary` `#f4ead6`，实测 1.10:1。这与提问卡、插件设置、自动化任务页属同一根因，修法一致。

## 约束

- token 优先：在面板容器内重绑 `--dsw-alias-bg-module-platform` 为 `#24261c`，不改插件源码、不逐单元格改色（`specs/项目规格/皮肤样式锚点.md` 写法要求 1）。
- 容器锚点只用 A 级：插件写在根 `section` 上的 `aria-label`（`原始数据` / `对话分组`，两个展示形式各一个根）。不写 `[class*='_root']` 一类 D 级 localName，面板类名前缀 `-vOKNW` 属构建期 hash。
- 作用域限 `:not([data-ds-dark-theme])`：暗色主题下该 token 本身是深色，不需改动。
- 底色取 `#24261c`（皮肤面板橄榄档），不新增色值。
- 卸载可撤回：规则只挂在 `body[data-dsh-815]` 下，body 属性撤回即失效，不写行内样式。

## 涉及文件

- `src/client/vj815.module.css`（「侧栏『会话数据诊断』表头」段）
- 无 JS 改动，无测试新增（jsdom 不覆盖 CSS 命中）

## 验收

1. 静态：过 `皮肤样式锚点.md` 验证清单第 1、2 条，新规则无 hash 选择器。
2. 运行时命中：在真实 GUI 里打开「会话数据诊断」页，
   `document.querySelectorAll("[aria-label='原始数据'], [aria-label='对话分组']").length` > 0
   （截图见下「实测记录」）。
3. 对比度（1600x900 本机客户端 GUI，逐元素扫 `<4.5:1`）：
   - 表头修前 1.10:1（`#f4ead6` on `#f5f6f7`），修后 12.85:1（`#f4ead6` on `#24261c`），五个列头同值；
   - 行正文、选中行、详情抽屉维持原深底档，重绑后不变；
   - 两态合计 `<4.5:1` 元素：修前 5 项，修后 0 项。
4. 两态：`原始数据` 与 `对话分组` 两个展示形式都验；展开行详情（底部「原始数据」抽屉）后再扫一遍。
5. 卸载：`body[data-dsh-815]` 移除后表头回到宿主原色，脚本侧由 `pnpm test` 覆盖卸载撤回。
