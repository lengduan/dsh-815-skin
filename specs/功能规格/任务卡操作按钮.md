# 任务卡操作按钮

- 状态：生效中（2026-11-20 建立）

## 目标

`dsh-deep-ptc-mode` 任务卡（`.dpt-tb`）条目上的操作按钮——确认 / 改 / 完成 / 重开 / 设为长期要求 / 删——一眼可辨、有明确点击区域，危险操作（删）与常规操作在常态就能分开。

## 约束

- 这排操作在插件里全是 `.dpt-pv-link`：纯文字、无底色、无边框、无内边距，靠 `.dpt-tb-tools` 的 `gap: 10px` 排成一行，只在条目悬停或聚焦时出现（`.dpt-tb-item:hover .dpt-tb-tools{display:flex}`）。
- 只改皮相、不动插件结构与行为：铜金细边 + 抬升底 + `padding: 0 7px` + `border-radius: 999px` 的小胶囊；hover 底走铜金 0.14（皮肤四档透明度里的 hover 档）。
- 危险项走插件下发的 `data-danger` 属性，常态红边红字，hover 才转红底，与设计风格第八条「非文字元素 ≥3:1」一致。
- 锚点：`[class*='dpt-tb']`（C 级固定名）叠 `body[data-dsh-815]` 收窄到任务卡子树；不用裸类名 `.dpt-pv-link` 去命中页面级同名元素，按 `specs/项目规格/皮肤样式锚点.md` 分级。
- 行为不变（点击、禁用、快捷键均按插件原样），禁用态按皮肤惯例压到半透明，保留胶囊形状。

## 涉及文件

- `src/client/vj815.module.css`（「任务卡（本次任务 v2）的条目操作按钮」段）

## 验收

- `body[data-dsh-815] [class*='dpt-tb'] [class*='dpt-pv-link']` 命中数与任务卡内实际按钮数一致。
- 按钮文字对胶囊底 ≥ 4.5:1（实测 8.88:1，与修前同为纯文字时持平，不降对比度）。
- 危险项常态红边红字、hover 红底；禁用态半透明且保留形状。
- 页面级其它 `.dpt-pv-link` 不被命中；禁用皮肤后不残留。
