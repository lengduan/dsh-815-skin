# 上下文洞察面板（dsh-context）

- 状态：生效中（2026-11-05 建立）

## 目标

dsh-context 插件在皮肤下保持可读：侧栏「上下文洞察」入口、会话页头「上下文 / 编队」视图 tab、全屏洞察页与右栏上下文面板里的文字都不与底色糊在一起。

## 约束

- 优先改主题 token / 插件暴露的 `--lc-*` 变量，只在其内部文字色与底色冲突时才加选择器；锚点按 `specs/项目规格/皮肤样式锚点.md` 分级。
- 插件用 `body:not([data-ds-dark-theme])` 判断深浅（`lib/client.js` 的 base.css 段），皮肤不改该属性，只在此分支上覆盖插件变量；选择器同时带 `[data-dsh-815]`，特异性高于插件原规则，不依赖样式表加载顺序。
- 不得为命中节点固化构建 hash 类名。

## 涉及文件

- `src/client/vj815.module.css`（`dsh-context` 浅色分支 token 覆盖段）

## 验收

- 全屏「上下文洞察」页：页底为深色玻璃，标题与时间范围分段控件的文字对比度 ≥ 4.5:1。
- 右栏上下文面板：`lc-core-kv` 指标卡底不再是近白，卡内标签与数字可读。
- 侧栏入口与会话页头 tab 文字对底色 ≥ 4.5:1（页头 tab 底为油画，按实际绘制区域取样）。
- `pnpm test` 通过；卸载/禁用皮肤后不残留节点。
