# 右栏全屏呈现

- 状态：生效中（2026-11-16 建立）
- 适用范围：`src/client/vj815.module.css` 中右栏全屏态的样式。

## 目标

DSH 官方右栏支持两种呈现：`push`（占视口右侧一列）与 `fullscreen`（`100vw` 覆盖层）。全屏时右栏铺满视口，而宿主给撑底容器写的 `background` 取 `var(--dsw-alias-bg-base)`，皮肤在 `vj815.module.css:22` 把该 token 定成 `transparent`（为了让油画透出来）。结果是 100% 视口被透空，底下的左侧边栏、对话列、输入卡整片透上来，和右栏内容文字互相叠压。

本功能让右栏全屏时成为一个干净的工作面：底层各列隐去、面板自带实底，退出全屏后一切恢复。

## 约束

锚点按 `specs/项目规格/皮肤样式锚点.md`：

- 全屏标记用 A 级 `[data-rightbar-fullscreen]`。来源：`dsh-client-ui-layout` 的 `AppFrame.tsx:302` `data-rightbar-fullscreen={layoutInfo.rightbarFullscreen || undefined}`，宿主手写、不参与构建 hash。
- 右栏面板用 A 级 `[data-sidebar-right-panel='fullscreen']`。来源：`dsh-client-ui-sidebar-right` 的 `SidebarRight.tsx:345`。
- 底层两列只能用 D 级 `[class*='sidebarCol']` / `[class*='centerCol']`，必须叠 A 级 `[data-rightbar-fullscreen]` 容器收窄，且必须写成直接子代 `>`（E 级辅助），避免波及别处同名元素。宿主这两列没有 `data-*` 可用：2026-11-16 实测 `sidebarCol` 只有 `class`，`centerCol` 只有 `class`。
- 不使用 `display: none`：宿主框架的栅格是内联 `grid-template-columns`（实测全屏态为 `280px 600px 720px`），移除列会让右栏的定位参考系（`rightbarCol`，`position: relative`）位移，全屏内容整体错位。只做视觉隐藏，不动栅格。

## 做法

1. 底层各列 `opacity: 0` + `pointer-events: none`。
   不用 `visibility: hidden`：2026-11-16 实测，宿主侧栏内部有 `.sectionLabel` 一类节点显式声明 `visibility: visible`，会在子代把 `visibility: hidden` 覆盖回来，`sidebarCol` 明明已 `hidden` 时「工作区」几个字仍然显示。
2. `[data-sidebar-right-panel='fullscreen']` 内局部重绑 `--dsw-alias-bg-base` 为 `var(--dsw-alias-bg-layer-2)` 并给自身实底。只在这个子树内改，不动全局 token——全局值决定了油画能否透出，是皮肤的基础设定。

## 验收

1. 命中数（本机 GUI 控制台）：
   - `document.querySelectorAll("[class*='frame'][data-rightbar-fullscreen] > [class*='sidebarCol']").length` = 1（右栏全屏时）
   - `document.querySelectorAll("[data-sidebar-right-panel='fullscreen']").length` = 1
2. 全屏态：左栏与对话列不可见、不可点（`elementFromPoint` 落在左栏区域时命中面板内元素或面板本身），面板为实底，右栏内容与油画不重叠。
3. 退出全屏：`sidebarCol` / `centerCol` 的 `opacity` 回到 `1`、`pointer-events` 回到 `auto`，左侧边栏与对话列完整可见可交互。
4. 未打开右栏、`push` 态下两条规则命中 0，视觉无变化。
5. `pnpm test` 通过（只覆盖 JS 侧，不能替代第 1~4 条的 GUI 实测）。
