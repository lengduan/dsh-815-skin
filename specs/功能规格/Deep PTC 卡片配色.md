# Deep PTC 卡片配色（特点卡片页与会话内提问卡 / 决策卡）

- 状态：生效中（2026-11-20 建立）

## 目标

`dsh-deep-ptc-mode` 的两类卡片在皮肤深底上可读：特点卡片页（`.dpt-pv`）的标题、主按钮「让模型引导设置」、空状态正文；会话内提问卡 / 决策卡（`.dpt-cc`，含 `ask_user` 落下的「需要你决定」卡）的标题、副行、选项与页脚，活动态与会话结束后的归档态都读得清。

## 约束

- 插件自带一层独立 `--cc-*` 调色板（`.dpt-pv` / `.dpt-cc` 各定义一份），按宿主浅色主题取值：`--cc-surface` ← `--dsw-static-neutral-50` `#fafafa`、`--cc-ink` ← `--dsw-alias-label-primary`。皮肤把 label-primary 重绑成奶油 `#f4ead6` 后，主按钮「底取 `--cc-ink`、字取 `--cc-surface`」变成奶油底配近白字。按 `specs/项目规格/皮肤样式锚点.md`「token 优先」，在卡片根上重绑 `--cc-*` 到插件自己暗色分支那一档，**不要逐条改 `.dpt-cc-btn` 的子属性**。
- 锚点用插件手写的 `dpt-pv` / `dpt-cc` 类名（C 级固定名，不参与构建 hash），叠 `body[data-dsh-815]`（B 级）收窄。禁止写裸类名 `.dpt-pv-link`：CSS Module 会编译成 `哈希_dpt-pv-link`，与插件 DOM 对不上，命中 0 个。
- 归档态 `.dpt-cc[data-archived]` 插件把它设成 `background: transparent`，会把卡底让给油画。按设计风格第三节「面板 = 深色玻璃」显式补回半透明橄榄底，保留虚线描边的「已归档」语义；不用 opacity 继续压（压的是可读性）。
- `--cc-ink-2` / `--cc-ink-3`（选项说明、副行、归档态 kicker）的插件浅色值 `#667085` 落到深墨卡底上只剩 3.0~4.0:1，按奶油五级提到 label-secondary 一档 `#c8c0a4`。
- 特点卡片页根 `.dpt-pv` 原先是完全透明，正文压在油画亮部（旗帜高光）时底色可到 `rgb(84,78,66)`，奶油字对比度掉到 5 上下；补同侧栏一档的玻璃底。
- 不改插件源码、不改节点结构；冲突一律注入式覆盖。特异度 (0,1,1) 高于插件的 (0,1,0)，不依赖样式表加载顺序。

## 涉及文件

- `src/client/vj815.module.css`（「特点卡片页」「会话内的提问卡 / 决策卡」两段）

## 验收

- `body[data-dsh-815] [class*='dpt-pv']` 与 `body[data-dsh-815] [class*='dpt-cc']` 命中数 > 0。
- 卡片正文与特点卡片主按钮对卡底 ≥ 4.5:1（实测 14.11:1，修前 1.14:1）。
- 卡片内逐元素扫描文字对合成底 < 4.5:1 的元素数为 0（修前 6 / 1 项）。
- 归档态（`data-archived`）同样可读：不再透油画，虚线描边语义保留。
- 禁用皮肤后不残留。
