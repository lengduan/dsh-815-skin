# 功能规格

单个功能或单块界面区域的规格放这里，一个功能一个文件，文件名用功能名（中文，如 `右栏改动面板.md`），并与需求里出现的叫法一致。

## 每份功能规格至少写清

- 目标：这个功能要解决什么、验收时看到什么。
- 约束：涉及样式的，逐条引用 `specs/项目规格/皮肤样式锚点.md` 的锚点规则；不得自行放宽。
- 涉及文件：预期改动的源文件与测试。
- 验收：可核对的条件（选择器命中数、对比度、浅色/深色两态、卸载后是否撤回）。

## 当前

- `右下角展签.md`：展签的层级与退场规则。
- `轨迹视图.md`：轨迹页形态标签、坐标轴与事件详情 JSON 树的深底可读配色。
- `Skill 上下文卡片.md`：Deep PTC 会话「当前上下文中的 Skill」卡片的深底可读配色。
