# 添加插件弹框提示条

- 状态：生效中（2026-11-20 建立）

## 目标

插件页「添加插件」弹框底部那条「请确认插件来源可信…」提示（两段说明）在弹框里读得清，不再是浅字压浅底。

## 约束

- 提示条是 `<p role="note">`，底是组件写死的浅奶油 `#fef5e7`，文字取宿主 `--dsw-alias-label-secondary`。皮肤把该 token 换成米色 `#d4ccb0` 后落在浅底上实测 **1.49:1**，属设计风格第八条「宿主已是浅底、皮肤压的浅字」。
- 按 `specs/项目规格/皮肤样式锚点.md`「token 优先」：只在提示条自身把 `label-secondary` 换成墨二级 `#4a4638`，**浅底不动**，与既有的提问卡、会话管理弹框同档取色；第二段那行未带样式的 `<span>` 一并继承。
- 锚点：`role="dialog"[aria-label='添加插件']` 与 `role="note"`，两者均为组件手写的 ARIA 语义（A 级），不带构建 hash；外层必须限定在这张弹框内——`role="note"` 是宿主通用的附件说明语义，别的弹框 / 面板也可能用（落在深底上，压墨会反过来看不清）。
- 不用 `[class*='installSafety']`：那是 CSS Module 的 localName，措辞会随组件版本改。
- 弹框体本身是皮肤深橄榄，标题 / 描述 / 安装源按钮在深底上已达标，本轮不动。
- 不改组件源码、不改节点结构。

## 涉及文件

- `src/client/vj815.module.css`（「添加插件」弹框段）

## 验收

- `body[data-dsh-815] [role='dialog'][aria-label='添加插件'] [role='note']` 命中 1 个。
- 提示文字对浅奶油底 ≥ 4.5:1（实测 8.73:1，修前 1.49:1）。
- 弹框内逐元素扫描文字对合成底 < 4.5:1 的元素数为 0（修前 2 类）。
- 其它 `role="note"` 不受影响；禁用皮肤后不残留。

## 已知边界

- 相邻警示图标是插件写死的琥珀 `#f59e0b`（对浅底 1.99:1），属非文字元素未达 3:1；换成铜金等于把「警示」画成品牌色，故本轮不动。
