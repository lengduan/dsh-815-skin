# 统计面板（会话顶部「统计」tab）

- 状态：生效中（2026-11-20 建立）

## 目标

会话页头切到「统计」后，表格里所有徽章与文字在皮肤深底上可读：红底「失败 N」徽章、绿底增量、计数徽章、工具名与数值列都不与底色糊在一起，行内彩色小段仍能区分。

## 约束

- 该面板是宿主 ui-session-stats 的 CSS Module（本机前缀 `O9N_wq_` 属构建期 hash，禁止作锚点），选择器一律写 `[class*='_localName']`（D 级），外层叠 `body[data-dsh-815]`（B 级）与 `[data-slot='conversation.view']`（A 级）收窄，按 `specs/项目规格/皮肤样式锚点.md` 分级。
- 徽章的字色由宿主写成 `color: var(--dsw-alias-bg-base)`（反色字）。皮肤为露出油画把 `--dsw-alias-bg-base` 定为 `transparent`（`vj815.module.css:22`），该 token 一旦被当作文本色就透明。**不要为了这个徽章改全局 bg-base**——对话列、输入座、右栏等多处依赖它透明；只在徽章自身补字色。
- 红底对白字的对比度：宿主原红 `#ec1313` 配白字实测 4.50:1，正落在 AA 线上；皮肤把底压到 `#e01818` 得 4.87:1，同时相对面板深底仍有 4.08:1 的可辨度。语义色（错误红 / 成功绿 / 警示琥珀）属于设计风格第八条允许保留的宿主语义色，提亮或压深都要记录实测值。
- 不改宿主与插件源码、不改节点结构；冲突一律注入式覆盖。

## 涉及文件

- `src/client/vj815.module.css`（「统计面板」段）

## 验收

- `body[data-dsh-815] [data-slot='conversation.view'] [class*='_failPill']` 在统计面板内命中数 > 0，文字对底 ≥ 4.5:1。
- 统计面板内逐元素扫描（含增量 / 计数 / 徽章 / 数值列）文字对合成底 < 4.5:1 的元素数为 0。
- 对话、轨迹、上下文等其他 tab 不受影响；禁用皮肤后不残留。
