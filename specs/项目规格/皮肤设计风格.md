# 皮肤设计风格

- 状态：生效中（2026-11-05 建立）
- 适用范围：`src/client/vj815.module.css`、`src/client/index.ts`、`src/client/titlebar-brand.ts`，以及后续一切视觉改动（新增面板、插件适配、新装饰件）。
- 本文管**视觉语言**；选择器锚点与验证清单另见 `specs/项目规格/皮肤样式锚点.md`。

文中行号均为 2026-11-05 读取时的位置，代码变动后以内容为准。

## 一、定位与叙事

皮肤是一件**史料展陈**，不是把名画当壁纸再盖满 UI。

- 底图：陈坚油画《公元一九四五年九月九日九时》（1945-09-09 南京受降）。
- 界面的角色：压在画上的**可读玻璃层**——画露在对话框、面板之间的留白处，其余表面保持深色、低饱和、不抢画。
- 叙事明线是「受降 / 终战」，材质暗线是铜金、橄榄、宣纸这套旧物语汇。装饰件只放四处（见第七条），不做民国风符号堆叠。
- 任何新增视觉元素先回答：它属于「画」「玻璃」「宣纸」还是「铜」？四类之外不新增材质。

## 二、色板

取色一律走变量或本表值，不在选择器里临时调色。

| 角色 | 值 | 出处 |
|---|---|---|
| 铜金（品牌 / 描边 / 选中 / 链接） | `#c4a35a`，亮档 `#e2c98a`，浅纸底用暗铜 `#6b4e16` | `--vj-brass`、`--vj-brass-soft`（`vj815.module.css:8-9`）、`:244-246` |
| 橄榄（面板 / 弹层 / 菜单） | `#24261c`（弹层）、`#2c2e24`（菜单）、`#1c1e16`（右栏 / 代码块）、`#3d4630`（实心按钮） | `--vj-olive`（`:10`）、`:724-749`、`:212-214` |
| 奶油（深底文字，五级） | `#f4ead6` / `#d4ccb0` / `#c8c0a4` / `#9e9780` / `#7e7866` | `:58-62` |
| 墨（浅底文字，五级） | `#1c1a14` / `#4a4638` / `#5a5443` / `#6a6454` | `:525-528`、`:1302-1308` |
| 宣纸 | `#f3ead4` → `#e4d6b4` 竖向渐变 | `--vj-paper`（`:12`）、输入卡 `:252` |
| 夜色 | `#080a06`（body）+ 竖向压暗渐变 + 椭圆暗角 | `:6`、`:122-131` |

规则：

1. **深底只配奶油五级，浅底只配墨五级**：同一屏内不许混用两套。混用必须先换底，再换字。
2. 铜金透明度拆成四档：`0.14`（hover 底）、`0.28`（选中底）、`0.42`（常规描边）、`0.7`（强调边）。新增透明度先落到这四档里。
3. 蓝、绿、红等语义色只在宿主语义要求时保留（diff 增删、错误、成功），且按第八条实测重选，不得直接沿用宿主为浅色主题选的色。
4. 不使用 GitHub 冷色系；插件自带的冷色面板（如 `dsh-rec-*`）按本表换成暖橄榄底 + 铜金链（`:798-852`）。

## 三、材质与层级

四层，从后到前：

1. 油画——body 背景，`background-attachment: fixed`，`center 42%`，随设备像素宽在 2K / 4K 间切换（`index.ts:163-172`）。
2. 压暗遮罩——`body::before`，`z-index: 0`：顶部 60% 起、中段淡到 38%、底部加深到 90%，另加椭圆暗角，保证文字区足够黑（`:116-132`）。
3. 内容——`[id='root']`，`z-index: 1`，背景透明，让画透出来（`:134-138`）。
4. 展签——`fixed`、`z-index: 0`、DOM 顺序在遮罩之后，故浮于遮罩。2026-11-11 实测：宿主把右侧抽屉 / 会话详情画在自身合成层上时，展签仍会透在内容之上；调 `#root` 的 `z-index`（1 / 2 / 100）都不能让内容盖住它，负 `z-index` 又会被油画底（body 背景）盖掉。因此展签按**背景级暗纹**处理：无底色板、整体不透明度 0.6、字号降一档；并在宿主页面出现底部操作栏（`footer`）或模态（`[role='dialog']`）时整块退场，避免压住按钮等正文。

- 面板 = 深色玻璃：半透明橄榄（`rgba(...,0.72~0.92)`）+ 铜金细线边框，阴影 `--vj-shadow: 0 18px 48px rgba(0,0,0,.42)`（`:13-14`）。
- 宣纸是**唯一浅底实卡**，只用于输入卡（`:234-255`）；行内 code、插件详情页的代码值、版本徽章等局部浅底胶囊可借用宣纸色，但必须同时把字压成墨色。
- 装饰层一律 `pointer-events: none`，不参与命中与焦点。

## 四、形状、描边与间距

- 圆角随体量：输入卡 18px、助手气泡 14px（左下角 6px 造成「贴住来源」的指向感）、侧栏入口按钮 12px、会话行与展签 8px、pill 与徽章 999px（`:251`、`:356`、`:903`、`:164`、`:639`）。
- 描边统一用 `--dsw-alias-border-*` 同族铜金：l1 `0.28`、l2-thin `0.36`、l2 `0.42`、l3 `0.7`、l4 `0.5`（`:27-35`）。其中 `l4` 皮肤必须自行定义——宿主给的是半透明黑，落在暗底上等于没有边框。
- 字号与间距跟随宿主，不自定义一套排版网格；皮肤只改色、底、边、圆角、字体族。
- 不加装饰性分隔线、网格、纹理贴图。

## 五、字体与排版

- 正文跟随宿主字体，不引入新字体文件（不增打包体积）。
- 只在「展陈性文字」上用衬线：首页 hero 标题 `Georgia, 'Times New Roman', serif` + `letter-spacing: 0.05em` + 深投影（`:227-232`）；右下展签同族（`:1229`）。
- 字距加宽只出现在品牌 wordmark 与展签副行（`0.14em`），正文不加宽。

## 六、图标语言

- 一律**线性描边 + `currentColor`**：`viewBox 0 0 24 24`、`stroke-width 1.7`、圆头圆角（`:15-20`）。
- 宿主下发的彩色实心图标（DeepSeek 蓝文件方块、蓝色文件夹 PNG、插件彩色贴纸）一律用 mask 重画，不保留原色（`:443-462`、`:1188-1210`）。
- 图标色随所在元素的文字色走，不单独设色；需要「更亮一档」时按所在底的奶油/墨层级取。

## 七、标志性装饰（仅四处，新增须先改本章）

| 装饰 | 位置 | 约束 |
|---|---|---|
| 青天白日海军旗 | 侧栏选中会话行左侧，16×11，内联 SVG | 只挂选中行，用于**标记归属**，不装饰其他行（`:157-193`） |
| 无鲸 wordmark | 标题栏居中，自绘 SVG，`currentColor` | 替换宿主默认品牌；`pointer-events: none`（`:1134-1152`） |
| 展签 | 右下角，主行画名 + 副行时间地点，右缘铜金竖线 | 衬线 + 两档字距；无底色板、整体不透明度 0.6（背景级暗纹，见第三节第 4 条）；有 `footer` 底栏或模态时退场（`:1216-1260`） |
| favicon | 油画 2K 缩略 | 与底图同源（`index.ts:295-302`） |

## 八、可读性纪律（硬约束，优先于装饰）

1. **正文与交互文字对底 ≥ 4.5:1**；非文字元素（边框、图标、选中块）≥ 3:1。低于阈值就提亮文字、换底或换字号档，不靠加粗/加阴影糊过去。本节是要求，不代表现状逐处已达标：存量偏差发现一处按本节修一处。
2. 每次样式改动在**真实 GUI** 里量计算样式并记录数值（改前 / 改后），数值写进 CSS 注释或交付说明。`pnpm test` 不验证 CSS，不能替代。
3. 输入卡（宣纸浅底）内部必须整体压墨：`label-primary` 及其余四级 token 就地重绑，不得让浅色 token 漏进去（`:234-255`）。
4. 宿主为浅色主题选的值落在皮肤暗底上会失效的方向有**两条**，必须分别判断：
   - 方向一：深色皮肤 + 宿主浅底元素 → 在元素内把文字压墨；
   - 方向二：宿主已改深底、皮肤早先压的墨字 → 恢复奶油层级（易漏）。
   两向都处理完才算改完，参考 `:518-521` 与 `:1270-1295` 这对现存案例。
5. 装饰不得降低可读性：展签、旗标等不得压在正文上。展签层级无法保证位于宿主浮层之下（见第三节第 4 条实测），故以「背景级暗纹 + 底栏 / 模态时退场」两层手段避免形成遮挡：前者降低视觉权重，后者保证不覆盖可交互控件。

## 九、动效

- 只允许颜色与阴影过渡，时长 0.18s、`ease`；位置/尺寸不做动画（输入卡 `:254`）。
- `prefers-reduced-motion: reduce` 下全部关闭（`:1264-1268`）。
- 不新增扫光、闪烁、悬停位移等表现性动效（宿主运行中的扫光 token 只做配色覆盖，不改动效本身）。

## 十、边界与不做清单

不做：

- 不重排宿主节点、不改宿主与插件的组件源码；只追加带 `data-skin-owner="815"` 的自有节点与 `data-*` 标记，冲突一律注入式覆盖。
- 不引入第二次网络请求：图像全部构建期 data URL 内嵌（`index.ts:6`、`scripts/embed-art.mjs`）。
- 不使用构建期 hash 类名（见 `皮肤样式锚点.md`）。
- 不新增拟物纹理、堆叠金色描边、多套渐变色系。
- 不为「更国风」引入新字体或图标包。
- 不把油画透明度作为唯一的层次区分手段——层次首先靠底色与描边。

## 十一、变更流程

1. 视觉需求先对照本文件：落在哪类材质、哪级文字层、是否需要新装饰。
2. 需要新增材料/装饰/色值时，先改本文件再加代码，不在 CSS 里静默扩色板。
3. 改完过 `皮肤样式锚点.md` 的验证清单，并在交付说明里给出实测对比度。
4. 发现既有规则与本文件冲突：以本文件为准改代码；本文件不合用时先改本文件。
